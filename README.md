# Ammo Tracker — Downloads

Windows app for tracking ammunition inventory, firearms, range trips, and reloading.

## Install

1. Download **AmmoTracker.exe** from the [latest release](https://github.com/Stevo238/ammo-tracker-releases/releases/latest).
2. Put it in its own folder (e.g. `C:\AmmoTracker`) — it stores its database and settings next to itself.
3. Double-click it. Windows SmartScreen may warn about an unrecognized app: **More info → Run anyway**. Allow the firewall prompt if you want phone access on your WiFi.
4. Your browser opens with an empty tracker. Optional: set up email under **Settings → Email**.

## Updating

The app checks this repository: **Settings → Updates → UPDATE NOW**. Your data is never touched by updates.
